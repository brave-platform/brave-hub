# UNIQUE BRAVE Marketplace 2.7 — Marketplace Control & Chat Upgrade

This release preserves the existing UNIQUE BRAVE marketplace and adds: 
- strict listing ownership enforcement for product/service edit, stock and delete actions;
- administrator override for marketplace content;
- admin-owned listings presented as UNIQUE BRAVE Marketplace rather than personal provider details;
- product/service message requests with accept/decline flow before normal negotiation chat;
- administrator marketplace chat-request inbox;
- user timeline and profile reporting with reasons;
- user collections/saved listings navigation;
- administrator suspend, restrict, banish and restore controls;
- audited 30-minute administrator controlled-account sessions;
- plan activation/rejection controls so paid features remain pending until admin verification;
- persistent session/control-token support;
- skip-enabled sponsored popup ads;
- migration 004 for chat requests and controlled account sessions;
- Node 22+/24-compatible runtime retained.

BRAVE World/game and AI video-generation projects remain separate products and are not included in this marketplace release.
