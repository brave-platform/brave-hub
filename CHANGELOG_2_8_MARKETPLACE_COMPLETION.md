# UNIQUE BRAVE 2.8 Marketplace Completion

- Added persistent database-backed product cart alongside local cart fallback.
- Added visible cart counts and Add to cart directly on product cards; opening a product is optional.
- General Marketplace now uses one mixed products + services feed; product/service marketplaces remain specialised destinations.
- Added live notification and pending-message-request badges with 5-second refresh.
- Added user-facing Message Requests inbox with accept/decline controls.
- Customer Care navigation is now shown only to accounts assigned the Customer Care role by BRAVE Admin.
- Added online Workshop links to Google Docs, Sheets, Forms, Canva and Photopea.
- Added a polished UNIQUE BRAVE wordmark/logo composition using the existing BRAVE lion icon.
- Added migration 005 for persistent cart storage and notification indexes.
- Preserved the existing admin controls, marketplace ownership rules, ads, plans, sessions, migrations, chat and account controls.

## GitHub
This package contains no `.git` directory and no real `.env` secrets. Copy `.env.example` to `.env`, set your private admin credentials and deployment values, then commit the project normally.
