# BRAVE 2.2 catalogue source note

The additional catalogue uses real product names and Nigerian-market reference prices checked against current Jumia Nigeria marketplace listings on 21 September 2026. Prices are stored as editable BRAVE Admin catalogue values; they are not claimed to be live Jumia prices and can change.

Reference pages used for the additional catalogue:
- https://www.jumia.com.ng/
- https://www.jumia.com.ng/mlp-all-categories/
- https://www.jumia.com.ng/mlp-all-products/
- https://www.jumia.com.ng/home-appliances/
- https://www.jumia.com.ng/mlp-super-deals/

Photographic product/service images are referenced from the Pexels image CDN in `backend/catalog_seed.js`. Admin can replace every image from the Published Catalogue Manager.

The BRAVE marketplace is an independent marketplace. "Jumia-style" means the UX pattern (mixed catalogue, category filtering, cart/order flow and payment choices), not a Jumia affiliation.
