# UNIQUE BRAVE 2.9.1 — Functionality, Admin Authority & Listing Identity

- Preserved the 2.9.0 architecture and features.
- Added an administrator authority/audit centre with authenticated admin identity, session/server details, audit history and ownership-integrity checks.
- Added an ownership-integrity repair operation that does not delete listings.
- Normalised official UNIQUE BRAVE catalogue listings so they do not carry member usernames.
- Public product/service pages now show a member profile only for member-owned listings. Official UNIQUE BRAVE listings show an official catalogue label instead.
- Public Edit controls are now owner-only for member products/services. Admin catalogue editing remains inside the protected Admin Centre.
- Added owner edit controls to product/service discovery pages for the signed-in listing owner. Backend ownership checks remain authoritative.
- Improved the Wallet page so its existing menu is functional and clearly explains current payment limitations without pretending a live wallet exists.
- Added migration 008 for listing identity normalisation.
