# UNIQUE BRAVE — Mobile Polish Release

This release is additive. Existing routes, APIs, marketplace behaviour, dashboard sections and working features are preserved.

## Mobile UX improvements
- Touch-friendly controls with 44px minimum targets.
- Safe-area support for phones with gesture/navigation areas.
- Mobile bottom navigation and menu sheet preserved and improved.
- Full-width mobile modals become comfortable bottom sheets.
- Better text wrapping for usernames, seller information and links.
- Horizontal overflow protection for tables and wide content.
- Responsive media sizing and mobile-friendly marketplace cards.
- Reduced-motion accessibility support.
- 16px form controls on mobile to reduce unwanted browser zoom.
- Products and Services pages now receive the same global mobile navigation/install layer.
- Public profile share links are easier to tap and copy.
- PWA cache version bumped so deployed mobile clients can receive the new UI.

## Preservation rule
No existing feature was intentionally removed or replaced by this polish layer.
